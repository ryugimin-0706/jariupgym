# 자리없Gym — 루틴은 있는데, 자리가 없다면

🖼 이미지: cover.png

> 헬스장에서 기구가 사용 중일 때, **기다리지 말고 지금 비어 있는 기구로 오늘 루틴을 바로 바꿔주는** 모바일 웹 서비스예요.

💡 **지금 바로 써보기** → [jariupgym.vercel.app](https://jariupgym.vercel.app)
휴대폰 카메라로 아래 QR을 찍으면 바로 열려요. 로그인·설치 없이 1분이면 시작할 수 있어요.

🖼 이미지: qr-card.png

---

## 이런 적 있지 않나요?

- 오늘은 가슴 하는 날인데, **벤치프레스에 사람이 있어서** 하염없이 기다린 적
- 기다리다 지쳐서 그 운동을 **그냥 건너뛰거나 일찍 끝낸** 적
- 대신할 운동을 찾으려 해도 **같은 부위를 자극하는 운동이 뭔지** 바로 떠오르지 않은 적
- 운동 앱 추천 루틴을 따라 하려는데 **우리 헬스장엔 그 기구가 없었던** 적

자리없Gym은 **"자리 없음" 버튼 하나로** 이 순간을 해결해요.

---

## 핵심 기능

### ① 자리 없음 → 3초 만에 대체 운동

🖼 이미지: screen-1-substitute.jpg

- 기구가 사용 중이면 **[자리 없음]**만 누르세요.
- **같은 부위** 운동 중에서 **지금 비어 있는 기구**로 할 수 있는 운동을 **추천 이유와 함께** 최대 3개 보여줘요.
  - 예: 바벨 벤치프레스 자리 없음 → **덤벨 벤치프레스** (같은 가슴 운동 · 비어 있는 덤벨 사용 · 비슷한 수평 밀기 동작)
- 고르면 오늘 루틴이 바로 바뀌고, **이미 한 세트 기록은 그대로** 남아요.
- 바로 바꾸기 싫으면 **순서 뒤로 미루기**도 돼요. 기구가 비면 "다시 비었어요"로 풀면 끝.

### ② 내 헬스장 기구에 맞춘 루틴

🖼 이미지: screen-2-recommended.jpg

- 처음에 **다니는 헬스장의 기구만** 골라두면, 모든 추천이 그 기구 안에서만 나와요.
- 루틴이 없다면 **추천 루틴**(가슴·삼두 / 등·이두 / 하체 / 어깨 / 복근)으로 시작하세요. 우리 헬스장에 없는 기구 운동은 같은 부위 운동으로 **자동으로 바꿔서 "내 헬스장 맞춤"**으로 표시해 줘요.
- 평소 하던 루틴이 있다면 "가슴 하는날", "등 하는날"처럼 **분할별로 그대로 등록**할 수 있어요.

### ③ 세트마다 무게·횟수 기록

🖼 이미지: screen-3-sets.jpg

- 세트마다 **무게와 횟수를 적고 ✓** 하면 돼요. 한 번 적은 무게는 남은 세트에 자동으로 채워져요.
- 다음 운동 때는 **[지난 기록 불러오기]**로 지난번 기록을 그대로 가져와요.
- 운동 중에 **세트를 추가**하거나 **다른 운동을 추가**할 수 있어요. 추가한 운동을 내 루틴에도 넣을지 물어봐요.
- 운동이 끝나면 **"기다리지 않고 N번 바꿨어요"**와 총 세트·총 볼륨을 보여줘요.

### ④ 헬스 초보도 쉽게

- 낯선 기구는 **ⓘ**를 누르면 어떻게 생겼는지, 그 기구로 어떤 운동을 하는지 알려줘요.
- 운동 이름 옆 **ⓘ**를 누르면 **3단계 자세 설명과 주의점**, 영상 검색까지 연결돼요.

### ⑤ 로그인 없이, 앱처럼

- 회원가입 없이 바로 쓰고, 기록은 **내 휴대폰에만** 저장돼요.
- **홈 화면에 추가**하면 앱처럼 열리고, 지하 헬스장처럼 **신호가 약해도** 열려요.

## 1분 만에 핵심 기능 써보기

1. QR로 접속 → **[시작하기]**
2. 기구 화면에서 **[대부분 있어요]** → **[다음]**
3. **[추천 루틴으로 시작할게요]** → **[이대로 시작하기]**
4. 홈에서 **가슴·삼두** 시작
5. 첫 운동의 **[자리 없음]**을 눌러보세요 ← **여기가 핵심!**
6. 추천 운동을 고르면 루틴이 바로 바뀌어요

💡 2번에서 **스쿼트랙**을 하나 빼보면, 추천 루틴의 하체·어깨 운동이 "내 헬스장 맞춤"으로 바뀐 걸 볼 수 있어요.

## 어떻게 추천하나요?

AI가 아닌 **규칙 기반**이라 결과가 예측 가능하고 빨라요.

| 조건 (모두 만족) | 점수 |
|---|---|
| 같은 세부 부위 (예: 허벅지 앞, 허벅지 뒤, 엉덩이) | 동작 패턴이 같으면 **+3** |
| 내 헬스장에 있는 기구 | 원래 운동과 다른 기구면 **+1** |
| 지금 사용 중이 아닌 기구 | 맨몸 운동이면 **−1** (기구 운동 우선) |
| 오늘 루틴에 아직 없는 운동 | 동점이면 덤벨·바벨 같은 **프리웨이트 우선** |

- 기구 **26종**, 운동 **87개**, 부위 **6개**(가슴·등·하체·어깨·팔·복근)

## 만든 방법

- **기술**: React + Vite + Tailwind CSS, 브라우저 저장소(localStorage), Vercel 배포, PWA(홈 화면 추가·오프라인)
- **과정**: PRD 작성 → 결정 사항 문서화 → 핵심 화면(자리 없음 → 대체)부터 구현해 하루 만에 배포 → 사용자 피드백으로 기능 추가(운동 데이터 확장, 기구 설명, 세트별 기록, 운동 추가 등)
